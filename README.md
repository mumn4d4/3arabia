# 3arabia🚗
An interactive 3D application that allows users to explore a car's components, understand their functions and locations, and view the internal structure of the vehicle.

## Project Goals
* Build an interactive 3D car anatomy application.
* Allow users to rotate and zoom the car components.
* Display the name, function, and location of each component.
* Allow users to hide and show components.
* Create an exploded view to explore the internal structure.
* Learn programming and 3D web developing while building the project.

  ## Learning Path
